# 整合后可靠性修复记录

本轮根据 `greenfrog-status-roadmap-2026-10-16.md` 实施修复。安装包仍属于尚未发布的 10.1.0 本地集成版本，使用独立交付文件名，保留此前安装包。

## 本轮实现

| 项目 | 修改后的行为 | 主要源码 |
| --- | --- | --- |
| 旧偏好类型校验 | 密钥仅接受字符串，字段/规则/菜单开关仅接受布尔值；异常值跳过 | `src/utils/greenfrog-migration.ts` |
| 快捷键迁移 | 先收集整组候选，再规范化和检查冲突；允许合法交换，冲突项不导入；保留已有新偏好 | 同上、`src/utils/shortcuts.ts` |
| 迁移摘要 | 记录导入数量及跳过的目标键和原因，不记录密钥值 | 同上 |
| 无效查询避免 | 所有输出关闭时零来源调用；仅选补充来源时不调用 EasyScholar | `src/modules/rules/tool-update-easyscholar.ts` |
| 来源独立时限 | EasyScholar 最长 12 秒，单个补充来源整体最长 9 秒；即使适配器不响应取消也释放等待 | `src/utils/journal-source.ts`、`src/utils/supplemental-journals.ts` |
| 部分成功保留 | 补充来源分别结算，独立收集失败；EasyScholar 失败时仍可写成功的补充指标，反之亦然 | 同上、评级规则 |
| 实际修改计数 | 分别报告返回、启用、新增键、修改键和移除键；比较实际前后值，重复查询不计为修改 | 评级规则中的 `summarizeEasyScholarChanges` |
| Extra 分隔符 | 使用每行最先出现的半角或全角冒号；值内冒号不改变键识别 | 评级规则 |
| 自动阶段记录 | 记录元数据、格式、评级三个阶段的状态及保存、失败、修改、警告数量；取消后跳过后续阶段 | `src/utils/automatic-workflow.ts`、`src/hooks.ts` |
| 批次结果归属 | runner 返回该次排队任务自己的结果，供阶段记录使用，减少依赖全局 `lastResult` | `src/modules/runner.ts` |
| 可查看的诊断入口 | 一般设置新增“查看迁移与自动处理状态”，显示迁移数量及最近一次自动处理阶段，并说明分别撤销 | 设置页、`src/modules/preference.ts` |

自动阶段记录仅保存在当前会话内，保留最近一次；公开 API `getLastAutomaticWorkflow()` 返回独立副本。它不声称实现跨重启历史数据库，也不把三个阶段合并为一次数据库事务。

迁移仍为一次性、尊重已有用户偏好的操作。此前已设置迁移完成标记的配置不会自动强制重导入，也不会自动重写当时已经导入或用户后来修改的设置。

## 回归测试

新增针对性单元测试覆盖：

- 错误偏好类型、已有偏好优先、迁移摘要不含密钥值。
- 与默认/用户快捷键冲突、合法交换和禁用快捷键。
- 全部输出关闭时零请求、仅本地补充来源时不请求 EasyScholar。
- 来源永久不返回、独立超时、父取消传播、计时器清理、部分来源成功保留。
- 新增/修改/移除计数，以及值未变化时零修改。
- 自动阶段完成、未启用、取消、异常和后续阶段跳过。

真实 Zotero 测试增加了设置诊断按钮、自动阶段记录，以及远程适配器永久不返回时仍保存其他来源成功结果的场景。受控网络响应测试不等于真实 EasyScholar 密钥或旧外部服务在线验收。

最终验收：324 项单元测试通过；Zotero 10.0.6 / Gecko 140 中完整 62 项测试通过，其中包含生产 XPI 安装；生产构建、TypeScript、ESLint 和 AutoCorrect 通过。新的交付包复制自本次真实安装测试使用的生产 XPI，并核对字节哈希。

真实运行期间修复了 Gecko 插件沙箱没有全局 AbortController 构造器时的窗口回退，并为此补充单元测试。测试中的假 DOI 解析和 Zotero 后台请求分别隔离，避免把无关请求误计为评级流量；这些调整没有关闭生产环境的 DOI 规则。
