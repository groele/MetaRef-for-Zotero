## 调用流程

### 手动更新期刊信息

1. 菜单或快捷键调用 `onLintInBatch`，取得当前选中、可编辑的普通条目并去重。
2. 选择清空旧 Extra 时，先准备确认步骤；取消后不执行后续规则。
3. `tool-update-easyscholar` 根据期刊或会议名称查询评级。EasyScholar 与选中的独立来源并行调用。
4. 各独立来源分别收集错误；单个来源失败不会抹去其他已返回的数据。补充来源单次请求上限 7 秒，公共请求层保留有限重试与取消。
5. 只合并启用且有有效结果的指标。旧别名随对应指标更新清理；人工备注、其他插件字段和未更新指标保留。
6. 开启“同时更新缩写”时，继续执行期刊或会议缩写规则。
7. 所有修改交回统一 runner 保存；规则失败回滚、事务恢复、并发控制和撤销沿用已有实现。

### 新增条目处理

1. 新增通知经过延时、总开关、条目类型、可编辑性及群组限制筛选。
2. 启用文章元数据自动补全时，以固定“仅补空、不改类型”参数运行元数据工具。
3. 再次检查插件生命周期和总开关，随后运行标准格式规则。
4. 再次检查生命周期和总开关，启用期刊自动查询时运行评级工具。
5. 自动路径不执行手动全量清空 Extra，也不重复追加一套缩写流程。

### 中文文章元数据

1. 有 DOI 等标识符时优先走现有翻译器及服务链。
2. 无 DOI 且题名含中文时，可以进入知网标题检索服务。
3. 发送公开检索请求；不复制上游硬编码 Cookie 或第三方凭证。
4. 按现有题名一致性规则筛选链接，要求唯一结果且域名为 `cnki.net` 或其子域，协议为 HTTPS。
5. 使用 Zotero Web 翻译器取得未保存的数据，交回已有规范化、身份检查、补空及保存流程。
6. 无结果、多结果、访问失败或身份冲突时，不采用该来源的结果；由服务链继续处理或报告问题。

## 四项补充指标的来源

| 指标 | 来源 | 当前有效性边界 |
| --- | --- | --- |
| 南农核心 | 上游内置的 2010 历史分类 | 本地可用；不是当年最新评级 |
| 南农高质量 | 南京农业大学 2024 查询接口 | 本次网络探测 HTTP 200，但样例返回 `tag: 0`，尚无正向匹配验收 |
| 复合影响因子 | 上游独立中文期刊代理 | 本次网络探测超时；无法保证旧服务仍可用 |
| 综合影响因子 | 同一独立中文期刊代理 | 同上；不是 EasyScholar 返回字段 |

四项默认关闭。设置页标明独立来源、历史年份及旧 HTTP 接口只发送期刊名。EasyScholar 密钥只发送至 EasyScholar HTTPS 接口，不转发至补充来源。

## 刻意保留的行为差异

- 输出字段与列表列分别控制；旧版共享开关迁移为两个新开关，但已有新设置优先。
- 保留 MetaFlow 原有默认项；不强制把全体用户改成绿青蛙默认选择。
- 首次迁移仅复制旧插件显式保存的用户偏好；旧默认值、旧列宽、显示顺序和排序状态不视为已迁移。
- 作者加粗、加星和移除合并到一个带动作选择的工具；并非逐一复制上游所有子菜单布局。
- 清空 Extra 需要显式确认，自动新增处理不会全量清空。
- 上游声明但未找到填充逻辑的“总结”列不作为已实现数据功能复制。
