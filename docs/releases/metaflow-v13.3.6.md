## 🎯 核心优化与布局调整

### 1. 侧边栏「信息」面板「撷论」行精准锚定于「其他」上方
- **视觉排版顺畅合理**：
  - 根据学术文献元数据阅读与编辑习惯，将右侧侧边栏「信息 (Info Pane)」中的「撷论」行从顶部 `position: "start"` 迁移至底部锚点；
  - 动态计算并精确插入至「其他 (`extra`)」行正上方，形成 `[文献常规元数据] -> [撷论] -> [其他] -> [添加日期/修改日期]` 的清晰视觉流；
  - 与下方直接存储论点内容的 Extra 附加字段形成直观呼应，既不遮挡顶部的条目类型、标题与作者信息，又便于快速查看与比对核心提炼。

### 2. 原生 DOM 树 MutationObserver 自动纠偏与自愈机制
- **抗异步重渲染干扰**：
  - 针对 Zotero 7 在条目属性变更、批量编辑恢复或标签页切换时执行的 `restoreCustomRowElements()` 内部重排流程，构建自动化 `placeTLDRBeforeExtra` 智能监听与纠偏体系；
  - 接入 `MutationObserver` 监听信息表格的子节点变动，一旦检测到 DOM 重排即刻在微任务及渲染周期内自动将「撷论」行置于「其他」行之前；
  - 严格设立幂等守卫（`tldrRow.nextElementSibling !== extraRow`），避免任何不必要的重排抖动或无限递归，且在插件卸载与窗口销毁时自动注销清理所有 Observer。
