# Zotero MetaFlow 10.5.0

- Display the journal name above rankings in the journal sidebar; conference items use their proceedings title.
- Consolidate ESI into one configurable column and one sidebar result. Retain saved ESI as an explicitly labelled fallback.
- Keep ordinary author-update messages out of the journal pane while preserving warnings and errors.
- Roll back plugin-owned changes after permanent save failures without discarding intervening user edits.
- Avoid redundant cache alias writes and unused custom abbreviation file reads; trim Semantic Scholar credentials before requests.
- Audit all visible preference bindings and test credentials through the actual settings controls and provider consumers.

Successful API responses retain the 72-hour cache policy. Incomplete journal information is completed by clicking the MetaFlow sidebar navigation icon. Metadata updates include journal information according to the configured mode and source priorities.

The settings matrix and detailed audit are in `docs/settings-audit-10.5.0.md`. Test results, supported host builds, package checksum and verification limits are recorded in `dist/verification.json`. Provider tests use controlled responses; authenticated account availability and dataset permissions are not claimed as verified.
