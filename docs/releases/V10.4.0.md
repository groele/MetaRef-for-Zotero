# Zotero MetaFlow 10.4.0

This release consolidates the journal tools, abbreviation database, settings and reliability improvements developed after 10.1.0 into the maintained project.

- Click the MetaFlow navigation icon in Zotero's right sidebar to complete incomplete journal information. Selecting an item or clicking the panel body does not start network requests. Repeated clicks share one running task; results and failures remain in the journal pane.
- Metadata updates now include journal rankings and indexes by default, with a separate switch in settings. Journal fields follow the selected blank/overwrite mode; ESI and Nature Index follow their independent API/local source priorities. Existing notes and unselected Extra fields are retained.
- Both manual metadata actions can restore deleted, partial or incorrect authors. Author correction is enabled separately from ordinary blank-field updates. Identity conflicts, invalid creator data and edits made while a request is pending are protected. Automatic imports retain their blank-only behavior.
- Successful EasyScholar and Semantic Scholar responses are cached for 72 hours in memory and in the Zotero profile. Credential-specific hashed keys isolate accounts; identifier aliases share stored paper responses. Old six-hour entries retain their original deadline. Failures are not retained as successful responses, and connection tests deliberately make a fresh request.
- Concurrent same-journal lookups share one request. Only outbound cache misses are throttled. A cold cache flush no longer discards entries saved by a previous session.
- Journal abbreviations use 44,304 JabRef mappings, 18 source profiles, optional custom mappings and offline ISO 4 fallback. Ambiguous matches preserve existing values; punctuation-distinct custom names remain usable.
- Settings use consistent collapsible cards and paired field controls. Context actions support primary menu, submenu or hidden placement. Icons use the layered origami wings artwork; ordinary success notifications close after approximately 1.5 seconds.

The add-on retains `metaflow@groele`, the internal `MetaRef` instance and existing preference namespace. Author: groele. Declared host range: Zotero 10.0–11.x; Zotero 11 validation is bounded to the tested development build.

Validation evidence and package checksum are recorded in `dist/verification.json`. Tests use controlled API responses: authenticated provider availability, account permissions, all remote dataset years, macOS/Linux and third-party plugin combinations remain outside this release's verification. Legacy Chinese impact-factor and NJAU services retain upstream availability limitations. This integration is not a claim of identical behavior to every upstream plugin feature.
