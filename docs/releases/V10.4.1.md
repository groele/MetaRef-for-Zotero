# Zotero MetaFlow 10.4.1

This patch retains all 10.4.0 features and fixes two issues discovered by the GitHub Linux regression run:

- Success notifications use a plugin-owned timer, so native mouse-over events cannot cancel automatic dismissal. Normal success messages close after approximately 1.5 seconds; warnings, errors and cancellation retain their separate delays. Starting another batch or closing the plugin clears the previous timer.
- Shortcut rows use consistent typography and width-based responsive breakpoints, preventing Linux font metrics from turning a wide row into an unnecessarily tall layout.

The sidebar refresh trigger remains the MetaFlow navigation icon. Clicking the panel body or merely selecting an item does not query APIs. Metadata/journal updates, author repair and the 72-hour success cache remain unchanged.

Validation results and the production package checksum are in `dist/verification.json`. Provider tests use controlled responses; real account permissions and all future Zotero versions are not guaranteed by these tests.
