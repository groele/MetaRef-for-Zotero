# Zotero MetaFlow 10.1.0

Release tag: `V10.1.0` (2026-10-16). Compatible with Zotero 10.0–11.x.

This feature release adds a manual EasyScholar journal lookup for journal articles and conference papers. Add your personal EasyScholar API key in MetaFlow preferences, then run **Look up EasyScholar journal information** from the item menu. Returned journal rankings and metrics are merged into Extra while preserving unrelated notes and fields; MetaFlow saves changes through its normal batch transaction.

EasyScholar requests use HTTPS and run only when the user invokes the tool. No key migration from the unrelated Green Frog add-on or plaintext HTTP services from the merged package are included. Automatic lookup on item addition remains off.

Validation: 289 unit tests passed; production plugin build, TypeScript check, targeted ESLint, and AutoCorrect passed. Authenticated live API requests and Zotero desktop E2E were not run in this integration checkout.
