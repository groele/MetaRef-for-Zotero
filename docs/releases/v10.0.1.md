# Zotero MetaFlow 10.0.1

Release tag: `V10.0.1` (2026-10-16). Compatible with Zotero 10.0–11.x.

This maintenance release hardens metadata correction and batch processing. Rules that detect suspicious field placement now report instead of deleting uncertain values; blank-field cleanup uses a conservative field whitelist, and manually curated short titles are preserved. Failed or timed-out rules roll back only their own writes while healthy rule results continue through the shared save boundary.

Metadata updates now reject contradictory identifiers, preserve user edits made during requests, validate item-type and creator-role compatibility, and fill missing fields from subsequent providers without overwriting values from earlier trusted responses. Request cancellation, HTTP timeouts, cache sharing, report export, and batch recovery also have expanded regression coverage.

The update feed and packaged add-on version are `10.0.1`. The existing add-on identity (`metaflow@groele`), `metaref` resource namespace, and Zotero 10.0–11.* compatibility declaration are retained.

Validation: 285 unit tests across 46 files passed; production build and TypeScript check passed; AutoCorrect passed. On Windows Zotero 10.0.6 / Gecko 140, 55 integration tests passed and the final production XPI installation test passed. Zotero 11 / Gecko 153 was not rerun on the release worktree. Package digest and detailed results are in [`dist/verification.json`](../../dist/verification.json).
