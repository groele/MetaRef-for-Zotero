# 12.5.3 CI layout-contract follow-up

The first cloud CI run completed 197 native tests successfully and failed one shortcut-layout assertion: the native row was 56.8 CSS px high while the test required at most 52 px.

The layout test and preferences CSS are identical between the preceding 12.5.2 source base (83b5b8e) and the 12.5.3 release commit (19e3efe). This failure does not identify a new runtime-layout regression in the cancellation patch.

The follow-up changes only the E2E layout contract. It retains the no-overflow, grouped-buttons and contained-actions assertions, and replaces the platform-specific absolute height ceiling with explicit one/two/three-track responsive structure, positive/nonempty tracks, font-relative compact spacing, measured content-fit and no vertical clipping. It does not shrink text, alter settings CSS, skip tests or change the published XPI. Native controls and system fonts are allowed to determine their intrinsic height.

The immutable v12.5.3 annotated tag and its published assets remain unchanged. A subsequent main-branch CI run validates this test-only follow-up independently.
