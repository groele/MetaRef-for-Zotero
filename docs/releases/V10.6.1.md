# Zotero MetaFlow 10.6.1

Maintenance release based on 10.6.0 (`635c397`), addressing verified audit findings.

- Fix OSF short-link and preprint-path identifier extraction.
- Skip unnecessary network validation for already-long DOIs while retaining short-DOI resolution.
- Improve title-case handling for geographic names and common acronyms, while preserving custom title terms.
- Preserve postdoctoral report types and existing university locations; only fill missing locations using exact institution matches.
- Change inferred PDF page ranges to review suggestions instead of writing unverified values.
- Report detected duplicate items as warnings while keeping search failures as errors.
- Suppress repeated journal-pane auto-completion briefly, with retries after item/settings changes and on explicit refresh.

Verification: 451 unit tests, production build, TypeScript, ESLint and AutoCorrect passed. The same production XPI passed 102 end-to-end checks on Windows Zotero 10.0.6 (Gecko 140) and 102 on Zotero 11.0-dev.5+dac1ad489 (Gecko 153). Coverage is limited to these Windows host builds.

Detailed audit findings and verification boundaries are documented in `docs/comprehensive-audit-verification-2026-10-17.md`. The production package SHA-256 is recorded in `dist/verification.json`.
