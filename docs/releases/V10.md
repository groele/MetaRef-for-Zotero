# Zotero MetaFlow V10

插件版本：`10.0.0`。GitHub 标签：`V10`。

- 为 Zotero 11 / Firefox 153 迁移，将设置页内联事件改为外部脚本和捕获阶段片段加载监听。
- 关闭设置窗口或禁用插件时统一释放设置事件；初始化等待期间禁用插件可阻止后续注册。
- 启动失败与清理异常分别处理，避免一个宿主注销操作阻断其余资源释放；同步栏目和菜单注销保持原接口行为。
- 侧栏刷新同时捕获同步异常和异步拒绝，增加冻结内建对象和生命周期回归。

- 名称改为 Zotero MetaFlow，插件 ID 改为 `metaflow@groele`，主页和自动更新路径迁移到 `groele/Zotero-MetaFlow`。
- 安装清单和更新清单支持 Zotero 10.0–11.x；保留原 MetaRef 设置空间。更换 ID 需手动安装并移除旧插件。

JavaScript 目标保持 Firefox 140。Zotero 11 开发版验证范围见 [兼容性审查](../zotero11-compatibility.md)。

本次按用户要求将 Zotero MetaFlow 的版本编号重新设为 10.0.0；插件 ID 继续为 `metaflow@groele`，宿主兼容范围继续为 Zotero 10.0–11.x。

验证：257 项单元测试通过；最终 10.0.0 安装包在 Zotero 10.0.6 和 Zotero 11 开发版中各通过 8 项设置页、平台和安装专项。此前完整回归为每个平台 50 项，计数及范围见 [验收记录](../../dist/verification.json)。

名称更正：插件显示名称统一为 `Zotero MetaFlow`，Zotero 与 MetaFlow 之间使用一个空格。版本号保持 `10.0.0`，标签保持 `V10`。
