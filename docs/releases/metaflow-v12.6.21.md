# Zotero MetaFlow 12.6.21

- 图片模式仅写入图片格式，不附带文本表示，避免粘贴目标优先选择文本；图片失败明确报错，不自动切换为文本。
- 分享预览与复制分开：预览不自动覆盖剪贴板；图片、文本、保存由用户选择。
- 保存采用原生文件选择器，并等待 PNG 字节实际写入后提示成功；取消不报成功，失败明确反馈。
- 卡片双列内容按实际宽度换行，支持长英文、中文和长指标；继续使用插件图标，新增卡片文案中英本地化。
- 预览具备对话框语义、焦点约束、Escape 关闭、焦点恢复和关闭/卸载清理。
- “期刊评级、索引与数据源”“期刊卡片与分享”“期刊名称缩写”作为同级功能模块；保留单层折叠，仅首组默认展开。内部子组减少卡片套卡片，移除非复选框分组的无意义已选数量。
- 分享模式标签缩短，预览模式隐藏无效的静默复制内容项；修正通知方位旧文案，保留 preference 键、默认值和绑定。

- 修复 Linux 窗口管理器异步调整原生去重通知尺寸后定位未刷新的问题，保留 Zotero 原生排列算法并追加有限重排。
