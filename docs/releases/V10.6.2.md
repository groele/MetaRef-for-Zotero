# Zotero MetaFlow 10.6.2

Patch release adding a dedicated local journal ranking index for EasyScholar and supplemental metrics.

- Save selected journal rankings to the MetaFlow profile index by default; optionally also write them to Zotero `Extra` from preferences.
- Match saved rankings by ISSN and normalized journal title, and display them in the journal pane and item-list columns.
- Preserve blank-only update behavior across local-index and `Extra` values; batch index writes to reduce repeated profile-file rewrites.
- Keep existing `Extra` values readable and preserve unrelated metadata.

Verification: 456 unit tests, static settings-binding audit, ESLint, AutoCorrect, TypeScript and production build passed. The production package was not installed in a live Zotero host during this release validation.

The local profile index is stored as `metaflow-journal-rankings-v1.json` and does not sync with Zotero libraries or other profiles.
