# Zotero MetaFlow 13.0.1

**Release Date:** 2026-10-30
**Release Type:** Patch Release (Documentation & Presentation Polish)

## 📌 Summary

Zotero MetaFlow 13.0.1 delivers an exhaustive, meticulous, and feature-focused overhaul of both Chinese and English documentation (`README.md` and `README.en.md`). It systematically details:
- **Journal Insights Sidebar**: Complete documentation of JCR quartiles, CAS tiers (Upgrade/Classic), Impact Factor (IF), CCF classifications, ESI subject categorizations, Nature Index 2026 recognition, and the revolutionary zero-residual-margin collapsible architecture introduced in v13.0.0.
- **Native Bulk Deduplication**: Comprehensive workflow guide on one-click lossless merging across entire libraries from within Zotero's native Duplicate Items view.
- **59 Governance Rules & ISO 4 Abbreviation Engine**: Detailed matrices for title capitalization (with chemical and proper noun casing preservation), abstract line-break cleansing, author name inversion remediation, DOI/ShortDOI standardization, and JabRef/LTWA offline algorithms.
- **Rich-Text Title Helper**: Clear instructions on using the floating formatting toolbar (`<i>`, `<b>`, `<sub>`, `<sup>`, `<span class="nocase">`).
- **Settings, Architecture & FAQ**: Tab-by-tab configuration guide, error-boundary protections, and troubleshooting steps.
