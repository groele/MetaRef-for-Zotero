# MetaFlow 10.2.2：隐藏菜单、减少弹窗与卡片内边距

## 菜单位置

设置 → 右键菜单设置。每个命令的位置现有三种：无（隐藏）、右键一级菜单、MetaFlow 子菜单。

“无”复用已有 menu.<命令> 可见性偏好，不引入第二套可见性配置。选“无”同时取消左侧勾选，并隐藏一级与子菜单两个入口；选择任一有效位置同时启用命令。取消勾选同步选“无”，重新勾选恢复此前位置。

## 运行反馈

默认不再自动打开“报告与字段变更”窗口。结果、警告、错误和字段变化保留于 runner.lastResult，不因减少弹窗而丢弃。

设置 → 常规设置 → 运行反馈与报告，显示上次运行摘要，提供“查看上次运行报告”。用户主动打开时仍可查看、操作并导出原有详细报告；也可显式开启“运行后自动打开详细报告”。结果保留至下一次运行或插件会话结束。

已有进度通知由原“格式化时提示”开关独立控制。需要输入参数、取消操作或确认删除的工具保留必要交互。

独立 ESI 和 Nature Index 右键命令改为刷新右侧期刊索引，不再单独弹出结果窗口。

## 日期误报修复

Zotero 的 JSON 访问日期可能为 ISO UTC，字段读取可能为 SQL UTC。以前逐字符串比较会误报“等待期间 accessDate 已发生变化”。现在按时间值判断这两种格式是否等价；真实时间变化继续视为并发修改并保留当前值。仅补空模式直接跳过已有字段，不为无需更新的字段生成并发修改提示。

## 卡片内边距

部分详细规则采用直接放置控件的折叠容器，原有边距又被复选框的高优先级 margin:0 覆盖。现在为该类容器统一创建内容区域，使用横向 13px 内边距；标题与内容对齐，并保留窄窗布局。其他分组继续沿用已有统一内边距，避免多层重复缩进。

## 验证

测试覆盖隐藏位置与勾选联动、两个菜单位置同时隐藏、两个窗口宽度下的复选框几何边距、警告不自动弹报告且仍可主动查看、UTC 日期格式等价与真实变化，以及既有设置/期刊索引/菜单/保存流程。

此次交付是本地安装包，未自动推送 GitHub。

验收结果：331 项单元测试通过，72 项完整真实 Zotero 测试通过；其中含隐藏选项联动、780/920 窗口宽度的边距与标题对齐、默认不弹报告及主动查看、显式开启自动报告后的实际文件导出，以及生产 XPI 安装。构建、TypeScript、ESLint、AutoCorrect 检查通过。
