# MetaFlow 10.5.0 设置与执行链体检

日期：2026-10-17。范围：当前维护主线的设置、规则、服务、缓存、侧栏、菜单和保存流程。机器可读逐项清单见 [settings-matrix-10.5.0.json](assets/settings-matrix-10.5.0.json)。

## 核验方法与结论

静态检查覆盖 263 个默认设置、118 个静态界面绑定，未发现缺失默认值、重复静态绑定或无法归属执行路径的可见绑定。动态生成的期刊字段、列、菜单和快捷键另由运行时测试覆盖。静态归属只证明连接存在；不能替代实际执行验证。

运行时测试在独立 Zotero 配置和数据库中打开真实设置面板、点击控件、读取偏好、执行规则并检查条目和界面结果。布尔绑定测试遍历可用控件并验证标准规则开关与启用规则集合一致；期刊字段测试分别验证全部 61 种字段的选择、写入和保留行为。服务测试采用受控响应，未使用用户密钥。

## 本轮发现并修复的问题

1. **ESI 重复列与开关不一致**：旧的固定 ESI 列与字段生成列并存，关闭后仍有列。现统一为 `esiDiscipline`，保留已存列布局；关闭开关可移除该列。侧栏也不再重复展示保存的 ESI；没有解析结果时使用明确标注的已保存值。
2. **侧栏混入无关元数据消息**：作者更新等普通信息曾进入期刊区。现只展示期刊相关普通信息，仍保留保存失败等重要警告和错误。
3. **永久保存失败后内存残留修改**：失败的插件改动可能被下一批次保存。现按修改日志逆序恢复插件写入，并保留执行期间人工修改；恢复失败会标记条目，后续强制重载。
4. **缓存命中仍重复写磁盘**：相同别名及相同期限不再安排持久化；新增别名才写入，不延长原始期限。
5. **未使用的缩写自定义文件仍被读取**：期刊内置/ISO 4 模式跳过无关自定义文件读取；会议自定义映射继续独立生效。
6. **Semantic Scholar 密钥首尾空格**：请求前规范化，避免粘贴空格导致认证失败及缓存分裂。
7. **侧栏缺乏期刊识别**：新增期刊全称标题，会议使用论文集名称，随当前条目刷新。

## 缓存与效率

成功 API 响应缓存 72 小时，兼具内存缓存和配置目录持久化；同资源并发请求共享任务，只有实际网络请求参与限速。旧缓存保留原到期时间，读取、添加别名不会续期。失败不会记为成功缓存；手动连接测试绕过缓存。刷新覆盖旧缓存是允许的。内置数据和索引延迟加载并复用，自定义数据按刷新策略失效。

## 交付边界

最终测试数量、主机版本与安装包校验值以 [verification.json](../dist/verification.json) 为准。Zotero 11 验证覆盖指定开发版，不代表所有未来版本。受控响应验证的是插件请求、解析、合并和异常处理；真实账号的额度、付费数据权限、远端数据库年份和服务可用性仍由提供方决定。没有声称与所有上游插件的全部历史行为完全一致，也没有验证所有第三方插件组合及 macOS。
