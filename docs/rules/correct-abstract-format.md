# 摘要排版规范化

在 MetaFlow 设置的“元数据规则 → 其他字段”中切换“规范化摘要排版”，默认启用。开启“新增条目时自动检查并整理”后，新导入的、有标题且可编辑的常规条目会自动执行本规则；关闭总开关或本规则开关即可停止自动规范化。

已有文献可选中后运行“检查并修复元数据”，也可在摘要字段菜单中单独执行“规范化摘要排版”。手动单独执行不受自动规则开关限制。

规则清理重复空白、缩进、零宽空格和独立的 ABSTRACT / 摘要标题，将段内断行合并为空格，保留空行分隔的段落以及已有行内格式。对独立断行的、可识别的化学式片段进行保守合并，例如 `WSe\n2\n/CuInP\n2\nS\n6` → `WSe2/CuInP2S6`、`Cu\n+` → `Cu+`。它不推测普通数字或文字的化学含义，也不自动给纯文本数字添加上下标。

处理直接保存到 Zotero 摘要字段，不改写措辞、不联网。对于空行究竟表示真实分段还是网页排版残留无法可靠判断的情况，优先保留分段。
