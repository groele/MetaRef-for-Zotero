# 科学文献元数据整理流程

## 使用入口

在 Zotero 设置 → Zotero MetaFlow →「标题 Title」中，勾选「自动整理标题中的化学式上下标」。此项默认关闭；开启后加入常规元数据检查，并在「Zotero MetaFlow：新增条目时自动检查并整理」开启时参与新条目整理。

「Zotero MetaFlow：检查并修复元数据」运行启用的本地规则，可选先联网补全或核验作者，最后更新期刊信息和核对重复文献。「Zotero MetaFlow：更新元数据」默认先按标识符核验，再整理格式并更新期刊信息；每个阶段可在同一设置区启停。PDF／标题回退、arXiv 版本关联和重复文献核对均为独立选项。两个命令按判据直接填充，不显示元数据确认窗口；身份不符或证据不足时保留原值并记录原因。“更新元数据”遵循补空／覆盖模式，“检查并修复”只补空。自动导入有独立开关，遵守作者修复选项，不扫描 PDF 或更改文献类型。

新增条目的自动整理在后台合并近邻通知，不阻塞导入通知；执行前重新检查自动开关和条目可编辑状态。群组文库有单独开关，依赖总自动开关。

「修复化学式内部及异质结构分隔符两侧的多余空格」独立控制空格处理。仅需要角标转换时可以关闭它。「右键菜单设置」中的对应开关只控制入口是否显示，不控制自动规则是否运行。

选中条目后，右键 → Zotero MetaFlow →「自动整理化学式上下标」可单独处理选中条目。分类右键菜单可使用相同功能。标题字段右键也有独立入口。这些手动操作不要求开启自动规则。

## 快捷键

| 操作 | Windows/Linux 默认组合 | 使用范围 |
| --- | --- | --- |
| 选区下标 | Ctrl + = | 标题编辑框中的选区 |
| 选区上标 | Ctrl + Shift + = | 标题编辑框中的选区 |
| 粗体、斜体、保持大小写 | Ctrl + B / I / N | 标题编辑框中的选区 |
| 检查并修复元数据 | Ctrl + Alt + L | 条目列表中的选中条目 |
| 自动整理化学式角标 | Ctrl + Alt + S | 条目列表中的选中条目 |

macOS 使用 Cmd 代替 Ctrl、Option 代替 Alt。快捷键按物理键识别，避免 Shift 改变符号或 Option 改变字符造成匹配失败。

在设置中点击输入框并按组合键即可录制，也可粘贴 `accel,alt,S` 等格式。Tab 切换输入框、Esc 退出录制、Backspace/Delete 禁用当前快捷键。每项都提供「禁用」和「重置」，重置可恢复默认快捷键。重复或无效组合不会保存，并显示提示；有效修改立即生效。功能、输入框、预览和操作按列对齐；窄面板将预览放到输入框下方，两个操作按钮始终成组显示。

富文本快捷键不会修改检索框、作者字段或其他输入框。未选择文字时不插入空标签；长按不会重复执行。再次操作选中的完整标签只移除该层标签，保留内部斜体等其他格式。

## 处理顺序

```mermaid
flowchart LR
  A[新条目 / 菜单 / 快捷键] --> B[过滤不可编辑和已删除条目并去重]
  B --> C[选择规则并去重]
  C --> D[每批次准备配置及数据]
  D --> E[按注册顺序逐条整理]
  E --> F[收集实际修改的条目]
  F --> G[事务保存]
  G --> H[进度及问题报告]
  H --> I[清理自定义文件缓存并保留内置索引]
```

1. 修改类入口经过统一批量分发；排除非普通条目、已删除和不可编辑条目。同一批中的重复条目或重复规则只执行一次。期刊索引菜单使用专用只读查询路径。
2. 批次串行排队，批内按并发设置处理条目。建议并发为 1；外部服务仍受各规则的节流约束。
3. 每条规则的准备工作每批只执行一次。准备失败的规则被跳过并报告，其他规则继续运行。准备上下文支持取消信号，标准规则准备默认限时 60 秒；工具设置窗口不自动倒计时，但可取消。同路径和相同解析配置的数据读取共享进行中的请求；失败不留在缓存中，以便重试。
4. 默认标题顺序是：移除尾部句点 → 标点规范 → 句式大小写 → 化学式角标 → 补充空白短标题 → 短标题大小写。短标题提取保留已有非空值；独立的短标题大小写规则仍由其开关控制。自定义术语正则在准备阶段编译，跨条目复用；单独执行角标规则只修改完整标题。
5. 每条规则按适用类型和字段有效性检查，默认 60 秒超时。抛错、超时或报告错误时，用字段修改日记撤销本规则的中途修改，保留此前健康规则结果及可区分的外部编辑；健康后续规则继续。恢复失败的条目被隔离，不再继续处理或保存，并尝试重新载入已保存状态。规则不能直接保存、删除或重新载入条目。结束后持有的条目接口拒绝后续修改和报告。
6. 所有规则及工具先修改条目内存，由批处理统一保存。批量事务失败时重新载入数据库状态，再恢复本批次整理结果并逐条重试，避免已经调用过 `save()` 的条目因变更标记被清除而漏保存。保存失败进入结果报告，并计入失败条目。正常批次在 Zotero 10 中支持整批撤销、重做；逐条重试路径的撤销按条目记录。
7. 点击停止后，取消当前任务的准备与在途规则，阻止晚到修改，保留已完成规则的修改并保存。排队中的核心任务停止不会取消无关任务。准备期间取消会释放等待队列，并关闭对应工具设置窗口；取消设置窗口会取消整个显式组合任务。插件关闭先取消任务，再完成保存与独立记录落盘。
8. 批次结束后清理自定义文件缓存及统计，即使批次退出异常也会执行清理；内置资源和索引跨批次复用。重复触发的后续批次按队列顺序运行；排队时捕获选中条目，不受之后切换选择影响。

数字去零只去前导零，不推断起始数字；`10-12`、`20-25`、`100-110` 和 `0-20` 保持原样。疑似外部工具写入的档案号、短标题等只提示核查，不再自动删除；标题中的 `None`、`无` 等文字保留。明确占位符仅在标识符或数字字段白名单中清理。

结果保留逐字段修改前后值、规则、可用的服务来源和实际保存状态；结果窗口可展开查看并导出 JSON。进度汇总区分保存、未变化、不适用和提醒数量。未保存的变化不会标成已提交。

## 化学式识别范围

| 输入 | 结果 |
| --- | --- |
| MoS2 / WS2 | MoS₂/WS₂ |
| ReS 2 | ReS₂ |
| CuInP2 S6 | CuInP₂S₆ |
| Fe(NO3)3 | Fe(NO₃)₃ |
| Fe3+ | Fe³⁺ |
| NH4+ | NH₄⁺ |
| SO4^2- | SO₄²⁻ |
| H_2O2 | H₂O₂ |

实际元数据保存为 Zotero 支持的 `<sub>` / `<sup>` 标记，保持可编辑性。元素符号按完整词元校验，允许小数计量比、括号和常见结构分隔符。已有上下标、斜体等标签及属性保留；`<span class="nocase">…</span>` 和 `<nc>…</nc>` 内的内容不自动转换。

四位年份、无效元素词元及不完整公式保持原样；前置系数和同位素数字不推断上下标。空格修复采用有限模式，不合并两个完整的多元素化学式。重复执行转换不会嵌套已有角标。

元素符号无法独自证明科学含义：`C4`、`P3`、`IC2` 或部分全大写缩写也可能被识别为公式。此类内容可用「保持大小写」标记保护，或关闭自动规则后逐批核查。这也是自动转换默认关闭的原因。

## 建议的整理步骤

先校对 DOI、文献类型和来源；需要时使用「更新元数据」获取数据，再运行本地规范化。先在少量选中条目上执行角标转换并检查结果，确认适合自己的文献类型后再开启自动规则。最后检查作者、年份、期刊名称及缩写、卷期页和结果报告中的问题。

期刊缩写仍使用已有的内置数据、自定义 JSON/CSV 和 ISO 4 推断流程。参考数据文件没有手工改写；更新仍使用项目的 `pnpm update-data`。

自定义缩写或 ESI 数据文件解析失败时，会报告原因并回退至内置数据。没有找到替代缩写时保留已有人工缩写。ESI 与 Nature Index 在独立侧栏和专用列表列中显示，不写入系列、档案、档案编号或标签。显示结果随当前条目元数据重新计算。内置 ESI 数据覆盖 Clarivate 2026 年第 6 期的 22 个学科和 12,245 条期刊记录。

「更新元数据」校验返回 DOI 与当前可信标识符的一致性；精确标识符／URL 查询可作为匹配依据，普通元数据搜索要求较强标题匹配及年份兼容。矛盾 DOI 不因标题相同而放行。预印本服务得到的关联正式 DOI 可用于后续查询。仅回显 DOI 不算完成更新；核心信息不完整时继续尝试后续来源，仅补充前一可信来源缺少的内容，保留较早来源的优先级并报告仍缺失的信息。

空响应、无效作者列表、非法日期及非字符串字段不会直接覆盖已有信息；等待网络时被外部修改的字段保留当前值。类型迁移会丢失字段或改变已有作者角色时保留原类型。Semantic Scholar 的纯全名作者仍不机械拆分，缺失作者通过结构化转换器或人工补齐。

公共 DOI／缩写查询共享进行中的请求，缓存最多 128 项、有效期 5 分钟；失败可重试，不缓存鉴权请求。单个等待者取消不影响其他等待者；全部取消才中止底层请求。请求默认限时 15 秒，429／503 仅按短退避重试一次，较长 Retry-After 返回错误而不提前重试。转换器等不支持中止的底层操作仍可能继续，其晚到写回由规则接口拒绝。

期刊索引菜单复用已加载数据；编辑自定义文件后，在设置页执行“重新读取”。它不再在每次查询时清空所有数据缓存。

页码补全仅用于 1–3 位正整数起始页，并且需要 PDF 的有效总页数。空页码、文章编号、小数和已存在的页码范围不会推断补全。作者缺失检查只报告问题，不会自动检索作者。

## 验证与范围

当前实现与环境见 [本轮审查](current-review.md)，通过数量及生产包散列见 [`dist/verification.json`](../dist/verification.json)。开发与测试命令见 [项目 README](../README.md)。真实 E2E 在独立资料库验证菜单、设置、保存、事务回滚、取消、超时、撤销、PDF 及生产包安装。外部服务采用受控响应验证。

批次结果分别统计规则准备失败、条目执行失败和跳过条目。静默批次保留报告记录而不打开报告窗口。当前清单面向 Zotero 10.0.x，实际运行验证使用 Windows Zotero 10.0.6。
