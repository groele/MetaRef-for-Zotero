# MetaFlow 10.2.0：统一设置、组合流程与菜单位置

本版包含此前绿青蛙功能整合与可靠性修复，并落实本次设置和交互调整。新版本含组合流程和菜单位置功能，使用次版本号 10.2.0；10.1.0 的旧交付包保留。

## 设置风格

一般设置、标题编辑、快捷键、右键菜单、详细规则以及关于等顶层区域，统一使用可折叠功能卡片。子功能区沿用相同的标题、箭头、边框、圆角、间距和字体规则，不再上下两套样式。

所有偏好复选框统一为可见的原生 HTML 复选框，具有关联标签、键盘操作和真实偏好持久化。同组连续勾选项按双栏排列，窄面板自动单栏。期刊指标按常规分区、收录体系、新锐、大学分类、自定义、独立补充来源及列表列分组；标题右侧显示已选数量。

按用户最新要求移除插件内搜索框、分区跳转及全部展开/收起按钮。各功能区通过自己的标题独立展开或收起。

## 两条主要命令的区别

| 命令 | 默认行为 | 扩展配置 |
| --- | --- | --- |
| 检查并修复元数据 | 运行已启用的检查与格式规则 | 可选加入文章元数据补空及期刊评级查询 |
| 更新元数据 | 从现有数据服务获取文章题录，按用户选择的补空/替换策略更新 | 设置面板“更新元数据 → 更新策略”中保存模式和类型选项；直接执行，不再弹出模式配置窗口 |

“更新元数据”处理的是文章题名、作者、日期、卷期页码等。EasyScholar 处理期刊和会议评级，两条数据链不混称。

## 组合流程设置

一般设置中新增“检查并修复元数据：组合流程”折叠卡片。可选择：

- 开始时获取文章元数据：固定仅补空、不改条目类型；默认关闭。
- 标题及短标题、作者、DOI、卷期页码、出版物名称、其他规则六组模块。
- 最后更新期刊分区及评级：默认关闭。

模块总开关与原有详细规则共用偏好。勾选时启用本组全部标准规则，取消时关闭本组全部标准规则，半选表示仅启用部分规则；单独修改详细规则也会更新父模块状态。具体规则的参数保留原设置，不会把所有参数选项机械改成 true。

组合流程复用已有 Rule 和 MetadataService，按规则 ID 去重，不增加第二套查询或格式实现。它不自动执行作者标记对话框、任意文本替换或清空 Extra 等手动维护工具。这些工具仍可单独从菜单调用。

自动新增处理继续使用其独立开关，不因手动组合流程加入远程步骤而重复查询。

## 用户选择一级右键菜单

右键菜单设置中，每个命令同时具有显示开关和位置选择：

- 右键一级菜单：直接出现在 Zotero 条目或集合右键菜单。
- MetaFlow 子菜单：放在插件子菜单中。

位置修改在下一次打开菜单时生效。已放入一级菜单的命令在子菜单中隐藏；取消显示会同时隐藏两个位置，避免重复项。两条主要命令默认直接显示，其余命令默认放在插件子菜单。所有入口调用同一套动作和保存流程。

## 期刊评级不再弹结果报告

单独运行 EasyScholar 期刊更新时静默执行，不弹出截图中的结果报告或进度窗口。期刊分区、影响因子和其他已保存指标显示在右侧“Zotero MetaFlow 期刊索引”区域，更新成功或失败也在该区域给出简短状态。

原有 Extra 数据保留为持久存储，不删除人工备注；面板兼容旧键名。文献保存后自动刷新，切换文献清除上一条的内容；查看面板不发起网络查询。ESI 和 Nature Index 仍显示在同一区域。

其他检查与修复操作保留已有结果报告。手动确认清空 Extra 的行为仍需显式选择，不因整合或模块勾选而自动开启。

## 验收边界

实际验证包括单元测试、真实 Zotero 设置窗口、卡片折叠、双栏几何位置、原生复选框点击持久化、模块父子联动、一级菜单位置及重复项、右侧评级显示、错误内联提示，以及生产 XPI 安装。

对照绿青蛙的常用期刊指标、大学目录、自定义数据、作者工具、名称交换、查找替换、缩写、自动更新和目录/快捷键功能沿用既有整合实现。部分旧接口仍未完成正向在线验收，真实 EasyScholar 密钥、知网实际抓取和 Zotero 11 的本轮验收也不能由受控响应测试代替，因此不宣称已经百分之百验证所有上游在线功能。

字段级来源的跨会话历史记录仍是独立后续工作。本地安装包发布与 GitHub 提交也是不同步骤，本次构建不自动代表已经推送 GitHub。

更新策略及 API 限流、中文检索和类型迁移说明统一放入设置面板。旧版“静默使用默认设置”开关不再显示，历史开关值不再控制弹窗。已保存的更新模式与允许更改类型偏好继续沿用。
